Challenge

The product's test automation framework was outdated and covered very little of the application. The automated tests had been written by software developers without a systematic approach, so the suite was hard to extend and coverage stayed low. Regression confidence depended on a small set of checks that nobody on the testing side owned.

My Solution

  • Built a proof of concept to show that a modern framework would work for this product before committing the team to it, then introduced Cypress as the updated test automation framework.
  • Set the structure around industry best practices: the page object pattern, fixtures, and reusable Cypress procedures, so new tests reuse existing building blocks instead of starting from scratch.
  • Moved ownership of test automation to the testing team, so coverage was planned and grown systematically instead of ad hoc.

Result

grew the number of automated tests from 50 to 2,200, with coverage now planned and owned by the testing team.
